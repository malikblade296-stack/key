Maintenance mode

How it behaves

  • Pause key timers freezes every activated key. When you turn it off, each key gets back exactly the time that passed — nothing is lost.
  • Close reseller page and activation page shows the maintenance message instead of the login/verify forms. Existing Happ subscriptions with a paused key keep their remaining time.
  • The timer still starts only on a key's first successful verification; unused keys never expire.

Turn maintenance off to restore normal access. Any paused key is extended automatically at that moment.
